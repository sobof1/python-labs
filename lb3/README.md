# Лабораторна робота № 3

**Варіант 15 — алгоритми розгалуженої та циклічної структури.**

## Склад проєкту

- `branching_logic.py` — обчислення та табулювання кусочної функції на відрізку `[-3; 4]` з кроком `0.25`;
- `series_tabulation.py` — рекурентне обчислення ряду Бесселя `J0(x)` з точністю `ε = 10⁻⁷`;
- `.vscode/launch.json` — дві конфігурації запуску й налагодження у VS Code.

## Запуск

```bash
conda activate ce_lab_env
cd lb3
python branching_logic.py
python series_tabulation.py
```

Для варіанта 15 у стандартному модулі `math` немає функції `J0`. Тому програма
перевіряє результат рекурентного алгоритму незалежним прямим обчисленням того ж
ряду; прямий спосіб застосовано тільки як контрольний еталон.

## VS Code у Windows з Miniconda

У `.vscode/settings.json` налаштовано профіль **Miniconda PowerShell**. Новий
вбудований термінал VS Code запускає `conda-hook.ps1` та активує базове середовище
`C:\ProgramData\miniconda3`.

Для лабораторної роботи краще обрати профіль **Miniconda ce_lab_env** через
кнопку `+` у панелі Terminal → стрілка поруч із кнопкою → вибрати профіль. Він
запускає той самий `conda-hook.ps1`, після чого виконує `conda activate ce_lab_env`.
Профіль потребує, щоб середовище `ce_lab_env` уже було створене.
