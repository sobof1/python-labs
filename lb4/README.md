# Лабораторна робота № 4

**Варіант 15 — обробка списків, кортежі та матричні операції.**

## Склад роботи

- `vector_algorithms.py` — генерація вектора з 24 цілих чисел у діапазоні
  `[0; 100]`, підрахунок частот, пошук мінімуму/максимуму та ручний
  Selection Sort;
- `matrix_operations.py` — генерація матриці `A` розміром `3×3`, обчислення
  норми Фробеніуса, добутку `A × A` і всіх сідлових точок;
- `.vscode/launch.json` — конфігурації запуску та налагодження у VS Code.

В обох модулях використано незмінний кортеж
`CONFIG = (N, M, K, X_MIN, X_MAX) = (24, 3, 3, 0, 100)` з паралельним
розпакуванням. Випадкові дані відтворювані: вектор генерується із зерном
`20261015`, матриця — із зерном `3`.

## Запуск

```bash
conda activate ce_lab_env
cd python-labs/lb4
python vector_algorithms.py
python matrix_operations.py
```

Модулі використовують лише стандартну бібліотеку Python і сумісні з Python
3.10+.

## Алгоритмічний опис

1. **Вектор.** Генерується список із `N` цілих значень. Частоти підраховуються
   через словник, екстремуми — через `min()`/`max()` та List Comprehensions.
   Для кожної позиції `i` алгоритм Selection Sort знаходить мінімальний елемент
   невідсортованої частини `i..N-1` і міняє його місцями з `V[i]`. Часова
   складність — `O(N²)`, додаткова пам'ять — `O(N)` для копії вектора.
2. **Матриця.** Для матриці `A` обчислюється
   `||A||_F = sqrt(Σ A[i][j]²)`, після чого виконується класичний добуток
   `A × A`. Сідлова точка шукається як елемент, що дорівнює мінімуму свого
   рядка і максимуму свого стовпця. Для `M×K` матриці така перевірка має
   часову складність `O(M×K)` після обчислення рядкових мінімумів і стовпцевих
   максимумів.
